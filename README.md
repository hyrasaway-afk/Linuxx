# Linux Downloader

واجهة الموقع مع backend يربطها بخادم Cobalt تملكه أو لديك إذن باستخدامه.

## تشغيل محلي
1. انسخ `.env.example` إلى `.env`.
2. ضع عنوان خادم Cobalt الخاص بك في `COBALT_API_URL`.
3. شغّل: `docker compose up --build`
4. افتح `http://localhost:3000`.

## ملاحظات
- هذا المشروع لا يتضمن خادم Cobalt مستضافًا أو مفتاح API.
- لا تستخدم واجهة API عامة دون إذن؛ وثائق Cobalt توصي باستضافة نسخة خاصة أو الحصول على تصريح.
- استخدمه فقط للمحتوى الذي تملك حق تنزيله، مع الالتزام بشروط المنصات.
- بعض المنصات قد تتطلب إعدادات إضافية، وقد تتغير آلياتها.
